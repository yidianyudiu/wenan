## 输出格式

严格按以下 JSON 输出，不要输出任何其他内容，不要加 markdown 代码块标记：

{"hook": "第一句话，15-35字", "body": "正文，包含问题放大、分点方案、结尾判断句，用\\n分段", "cta": "结尾行动号召，15-35字"}

注意：
- hook 的内容必须同时是 body 的开场语境，但 body 里不要重复 hook 原句
- body 的最后一句必须是一句经营判断，不能是分点，也不能是总结陈词
- 全文 300-500 字
- 不要写"以上就是"、"希望对你有帮助"这类收尾
