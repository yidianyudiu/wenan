# 屿洁说干货 Growth Workbench V0.1｜简洁 PRD

## 产品目标

把 Content OS V1.0 封装为内容团队每天可打开的本地工作台，形成“机会—选题—脚本—审稿—发布—数据回流”的可操作闭环。

## 核心用户

- summer哥：选题决策、审稿、发布与经营判断。
- 内容协作人员：资料、灵感、账号和表现数据的日常录入。

## V0.1范围

1. 今日作战台：推荐选题和关键状态。
2. Topic Pool：八类状态流转，强制 `customer_problem_orientation`。
3. Content Studio：每题仅生成1条候选稿，证据与风险折叠展示。
4. 人工审稿：直接拍、修改后拍、不拍；反馈进入 Calibration Data。
5. Inspiration Inbox：链接/文本收件与结构拆解，永久标记 External Inspiration。
6. Knowledge Inbox：文件哈希去重、分类、候选状态与现有解析流水线队列。
7. Creator Intelligence：A/B/C账号手动管理。
8. Performance Intelligence：内容唯一ID及24h/72h/7d/30d结构；V0.1提供24h手动录入界面。

## Usability Fix 01 覆盖规则

- 日常入口收敛为5项主导航；账号观察和内容数据移入“设置与数据”。
- 一个主题先生成4个切口，默认只生成用户选择的1篇完整稿。
- Content Studio 只有一套状态；所有版本只新增、不覆盖，可查看和恢复旧版。
- 人工审核只保留“哪里有问题”“修改建议”，不拍时增加“整体问题总结”。
- 灵感链接必须先取得正文/字幕才分析；受限页面明确失败并提供人工补充入口。

## 不在V0.1

- 自动抓取抖音、小红书、视频号。
- 自动连接平台后台。
- 100条Topic Pool或脚本批量生产。
- 自动升级pending知识、外部观点或Brand Thesis。
- 替换现有Topic Agent、Script Agent或数据库。
